The repository documents my work and learning throughout university, showing how programming can be applied in academic contexts.

## 📌 About this repository

The activities in this repository were developed as part of university courses and projects. Each one addresses a different topic or problem and may use different programming languages, tools, or methods depending on its goals.

The focus is on applying programming and computational thinking to practical tasks, supporting problem solving, analysis, and the development of solutions.

The repository is organized by subject, course, or activity. Each folder contains the materials related to a particular piece of work, such as source code, notebooks, documentation, or supporting files.

The contents and organization may vary depending on the requirements of each activity. Consult the files in each folder for more information about that work.
